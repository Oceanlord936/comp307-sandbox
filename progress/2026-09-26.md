## Concepts worked through
- New node is in memory only until attached; forgetting the attach step fails silently
- `parent.insertBefore(new, reference)` / `parent.replaceChild(new, old)`: called on the DIRECT parent, new node first
- `childNodes` includes whitespace text nodes; `children` / `firstElementChild` / `lastElementChild` / `nextElementSibling` are elements only
- Appending/inserting a node that's already on the page MOVES it; a removed node can be re-attached (`removeChild` returns it)
- `el.remove()` removes `el` itself (argument ignored); `parent.removeChild(child)` removes a child
- `null` errors: passed as argument → "parameter 1 is not of type 'Node'"; method called on it → "Cannot read properties of null"
- `getElementsBy...` (plural) → collection: `[i]`, `.length`, no `.style`, loop to style. Built-in: `document.links/images/forms/anchors` (properties, no `()`)
- `let` inside one function isn't visible in another
- Canvas: (0,0) top-left, y down; plan path then `stroke()`/`fill()`; `beginPath()` before each shape; size via attributes (CSS stretches the 300×150 default); outside = cut off
- `arc(x, y, radius, start, end)` in radians, clockwise from 3 o'clock; text y = baseline; `fillStyle` / `strokeStyle`
- SVG: shapes are DOM elements (`getElementById`, `setAttribute`, events); `cx/cy` = center, `rect x/y` = top-left; unknown attributes silently ignored
- State lives on the element (`style.display`, `classList`), not in a shared boolean
- `style.display` reads the inline style only (`""` at first), so CSS decides which `if` test works on the 1st click
- `classList.toggle/add/remove/contains`; the class is added live (F12 Elements, not the source)
- Arrow functions have no own `this` → use `function` or `e.target`
- JS flips a class, CSS in `<style>` does the look (vs writing `style.xxx` from JS)
- HTML `class` ↔ JS `className` (one string); `+=` needs a leading space; `=` replaces everything
- `.a.b` = one element with both classes; `.a .b` = descendant; `a, b` = either
- `.parent:hover .child { display: block; }`; relative parent + absolute child; `z-index` on positioned elements
- `@media type and (feature)`: `and` = both, comma = or; `max-width` / `min-width`
- `:not(:first-child)`; equal specificity → later rule wins
- `float: left/right/none`; parent needs `overflow: hidden` to wrap floats
- Tabs = reset all, then turn on one; accordion = each item toggles itself
- Drag & drop: `ev.target` differs per handler; `dataTransfer` carries the id between events; `dragover` must `preventDefault()`
