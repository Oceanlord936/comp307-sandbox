Table 1 stays 400px wide even though the three columns each ask for 200px (600 in total). The browser shrinks them together. cellspacing="10" gives the grey gaps between cells and around the outside. cellpadding="10" is the space between each cell's edge and its text. Table 1, row 2 has only 2 cells, so its second cell looks stretched or the row looks short. It's just a row with fewer cells. Table 2: the widths are 1% / 2% / 1%, but the columns come out as about 25% / 50% / 25% of 500px. Only the ratio between the numbers matters. Table 2, row 2: "centered text" is centred both ways, "right + top" sits top-right, and "left + bottom" sits bottom-left.
