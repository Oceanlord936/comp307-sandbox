The event name has to be one the browser actually fires. It's a fixed list, the same one the on... attributes use, just without the "on":

Attribute addEventListener name
onclick "click"
onkeydown "keydown"
onmouseover "mouseover"
onload "load"
onfocus / onblur "focus" / "blur"
onchange "change"
oninput "input"

Typo trap: addEventListener("clic", f) gives no error. The browser never fires a "clic" event, so the listener silently never runs.
